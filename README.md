# No-code Analytics Platform

A no-code analytics platform that lets you attach events and track user interactions visually — without writing tracking code manually. Open your website, select any element directly from the UI, and configure custom events, metrics, funnels, and user actions in seconds.

✨ Features

- 🎯 Select elements directly from your website
- ⚡ Attach analytics events without coding
- 📊 Track clicks, interactions, conversions, and custom metrics
- 🧩 Visual event management dashboard
- 🔥 Real-time analytics workflow
- 🛠 Developer-friendly integration
- 🚀 Designed for SaaS, startups, and modern web apps

## Why This?

Traditional analytics tools require developers to manually write event tracking code for every interaction. This project removes that friction by making analytics visual, dynamic, and no-code.

Instead of:

```js
track('signup_button_clicked')
```

You simply:

1. Open your website
2. Select the element
3. Configure the event
4. Start tracking instantly
